# Jaatri fare estimates and checkout quotes

- **Estimate:** Booking, the ride assistant and search use the class tariff from `GET /api/vehicles/pricing`, plus the route distance available at that stage. It returns persisted admin rates merged onto per-class defaults and never writes pricing configuration. When its database read fails, it identifies the default rates as estimate-only. Estimates are not promises and do not apply account-specific referral or cancellation amounts.
- **Authoritative quote:** Signed-in checkout calls `POST /api/booking/quote` with vehicle class and ordered pickup, stops and destination coordinates. The server calculates road distance and ETA; it does not trust submitted km, fare, dues or discount amounts. If the routing provider is unavailable, an estimated route is explicitly marked. The quote includes the current tariff, itemized GST/adjustments, remaining Student Pass allowance or eligible first-ride referral, and existing cancellation dues as a separate line. Quote requests do not reserve discounts, write a booking or notify drivers.
- **Review and request:** Checkout shows the amount from the quote and prevents requesting a ride without it. `POST /api/booking/create` runs the same server quote logic, then compares the result with the whole-INR amount reviewed by the rider. If it changed, it returns `409 FARE_CHANGED` with a refreshed breakdown before matching or dispatch. The rider must request again. A student allowance race also triggers a fresh review rather than silently changing the amount. The saved breakdown and amount become authoritative; later account-balance changes do not rewrite the displayed fare.
- **Class limits:** The established maximum of 100 km for local service is further restricted by each class's tariff. A car choice beyond 100 km displays and uses Jaatri Intercity's existing dedicated rates and route limits. If the server’s distance crosses the threshold unexpectedly, checkout rejects the local quote and offers an explicit request for the intercity quote. It never substitutes the class automatically. Cargo keeps its own min/max tariff ranges.
- **Accounting:** Fare math uses integer paise for base and platform charges, surcharges, discount and ledger reconciliation. Distance is billed in 0.1 km increments. Existing whole-INR rounding for distance, taxes and distance-based adjustments remains; decimal configuration that changes the reconciled result is shown as a rounding line. The current wallet and settlement amounts remain whole INR. No new prices, tax rates, fees, or promotions are introduced.
